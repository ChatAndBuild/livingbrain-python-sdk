# Living Brain Python SDK

The official Python SDK for the [Living Brain](https://livingbrain.com) API — a persistent,
evolving intelligence layer that turns what your users read, write, and say into a knowledge
vault that compounds.

```bash
pip install livingbrain
```

## Documentation

- **API reference and guides:** https://livingbrain.ferndocs.com
- **Python SDK guide:** https://livingbrain.ferndocs.com/sdk/python

## Generated code

This SDK is generated by [Fern](https://buildwithfern.com) from the Living Brain OpenAPI
spec. Source of truth lives in
[fern-demo/livingbrain-config](https://github.com/fern-demo/livingbrain-config) — open
changes there, not here, or they'll be overwritten on the next generation.
